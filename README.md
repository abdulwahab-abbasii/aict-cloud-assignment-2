# Sensor Readings Analysis (CS-117 Assignment 2)

## Project Purpose
This Python script reads a list of sensor values and calculates the total count, minimum value, maximum value, and average. It demonstrates hosting and documenting code on GitHub.

## Dataset & Expected Output
- **Sensor Readings:** `[22, 24, 26, 28, 30]`
- **Count:** 5
- **Minimum:** 22
- **Maximum:** 30
- **Average:** 26.0

## How to Run
1. **Google Colab:** Open [colab.research.google.com](https://colab.research.google.com), create a new notebook, paste the code from `sensor_readings.py`, and run the cell.
2. **Python (Local):** Download `sensor_readings.py` and run `python sensor_readings.py` in your terminal.
